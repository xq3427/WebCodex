# 本地面板（0.14.0-preview.2）

本地面板用于查看当前设备、工作区、官方连接和已记录任务，并协助把原文件交给 ChatGPT 原生附件入口。它独立于 MCP daemon，只读打开已有状态，不取得 daemon 的独占锁，也不新建或迁移运行数据库。

## 启动与配置

在已构建项目的终端运行：

```text
node dist/src/cli.js panel --config /absolute/private/config.toml
```

使用项目默认配置时可省略 `--config`。Windows 可用 `D:/WebCodex/config.json`，不同设备填写各自的真实路径。面板、`connect` 和配置管理命令使用同一份 JSON/TOML，选择顺序及路径规则见[统一配置](local-configuration.md)。

可选端口设置属于同一配置：

```toml
[localPanel]
port = 8767
```

JSON 对应 `"localPanel": { "port": 8767 }`。端口为 1024–65535 的整数，默认 8767。监听地址固定为 `127.0.0.1`，不提供公开地址、域名或远程绑定配置。面板端口与 `http.port` 的 MCP HTTP 端口相互独立。

启动后终端只打印一次启动 URL，例如 `http://127.0.0.1:8767/#token=...`。在同一台设备的浏览器中打开完整 URL，并保持进程运行；按 `Ctrl+C` 关闭面板。官方 MCP 隧道继续在原终端独立运行，打开面板不会启动第二个 daemon，也不自动创建或连接隧道。

**完整启动 URL 含本次面板的临时凭据，需要保密。** 不粘贴到 ChatGPT、issue、共享截图或公共日志，也不用配置中的 API key 替代它。凭据只对本次面板进程有效，停止或重启后旧链接失效；这不是承诺在固定几分钟后自动过期的登录链接。

页面从 URL fragment 取出凭据后清除地址栏片段，尝试保存在该本机页面会话的 `sessionStorage`，刷新可继续使用；浏览器禁止会话存储时仅保留在当前页面内存。它不写长期 `localStorage`，不加载外部脚本、字体、CDN 或分析资源，请求只发到本机同一来源。清空页面会话后需从当前终端重新打开完整链接。页面地址和 API 都有 Host/Origin 检查，不能将 `localhost` 或其他主机名随意替换进生成的地址。

## 读取状态

面板将几类事实分别展示：

| 内容 | 能说明什么 |
|---|---|
| 设备名称、ID、版本和配置路径 | 当前面板读的是哪份本机配置与构建 |
| 工作区根、权限和健康状态 | 当前可浏览的授权目录；离线或身份变化的目录会单独显示 |
| 官方隧道进程、MCP 就绪、OpenAI 轮询 | 当前获得的连接证据；面板能打开不等于 ChatGPT 已连通 |
| 工具响应计数与协议诊断 | 是否观察到请求及受限错误类别；响应已发送不证明业务成功或网页呈现 |
| 作业状态、退出码和输出 | 只读数据库中的记录，不是实时终端或操作系统进程存活证明 |

点击刷新重新获取状态。`unknown`、证据不足、离线与失败应按其原含义处理。输出只提供初始记录的有界片段，并进行常见凭据脱敏；需要完整输出或持续等待时，在 ChatGPT 使用相同 job ID 调用 `exec_poll`、`exec_wait` 或 `exec_tail`。面板没有启动、取消作业或发送标准输入的接口。

面板允许查看离线工作区的诊断，不因此放宽目录访问权限。目录被替换、关闭或不再符合授权策略时，不能用旧页面继续浏览。缺少状态数据库时显示暂无记录，不会为了展示状态启动服务或创建数据库。

## 定位原文件并在 ChatGPT 上传

1. 在面板选择目标工作区，进入目录并点击文件，也可输入工作区内相对文件路径。
2. 查看名称、绝对路径、大小、基于扩展名的 MIME 提示，以及预算内可计算的 SHA-256。
3. 点击“复制完整路径”，在 ChatGPT 的原生文件选择框中选取文件；或点击“打开所在目录”，从本机文件管理器把原文件拖入 ChatGPT。
4. 在 ChatGPT 中等待附件处理完成，再提问文件正文中未在提示里给出的内容，核对回答。

Windows 文件选择框通常可以在文件名栏粘贴完整路径。其他系统使用其文件选择器或文件管理器的路径定位功能；如果自动复制不可用，面板会选中路径供手工复制。“打开所在目录”只请求文件管理器打开父目录，不执行该文件，也不会把面板链接当成附件上传。

面板不解析 PDF、Office、压缩包或图片，不做 OCR、转换、文本提取或摘要。哈希基于原始字节，预算取自 `limits.fileReadMaxBytes`，默认 16 MiB。超过预算显示“未计算哈希”，仍保留定位、复制路径和打开所在目录；不截断文件，也不限制 ChatGPT 的原生上传大小。

面板没有向 ChatGPT 上传文件的接口，也不观察外部聊天的附件状态，因此文件信息中的 `upload_status: not_uploaded` 和 `model_access: unverified` 不会因用户另行上传而自动变为成功。只有在 ChatGPT 中实际选择附件并核对正文回答，才能确认那份附件可读。文件之后有修改，应重新核对上传版本。详见[原文件说明](original-files.md)。

## 接续本地 Codex 会话

先在同一配置启用专用历史读取，设置正确的 Codex home，并重启面板：

```text
node dist/src/cli.js codex enable --home /absolute/codex-home --config /absolute/private/config.toml
```

面板只读列出当前工作区匹配的会话索引。选择“复制接续请求”后，将请求粘贴到已连接这台设备的 ChatGPT 对话。请求要求模型先通过 `system_status` 核对设备，再用 `codex_session_handoff` 读取所选会话的可见上下文，检查当前文件与 Git 状态后说明下一步。

这一步复制的是接续请求，不是把历史全文偷偷加入当前聊天。面板不恢复模型隐藏上下文、不修改 Codex 数据库、不重放旧命令或启动原进程。会话索引有分页及扫描预算，当前页没有匹配记录不一定意味着不存在历史。详情见[Codex 应急接续](codex-emergency.md)。

## 配置改变与常见问题

面板启动时保存一份配置快照。修改设备名、工作区、Codex home、端口或权限后，关闭面板进程并重新执行 `panel --config ...`，再使用新 URL；需要 MCP 使用新配置时也应正常重启官方隧道。

- **端口占用**：停止旧面板，或在 `localPanel.port` 改为另一个允许端口；不要把面板绑定到公网。
- **等待本机授权/401**：使用当前面板终端打印的完整 URL；旧进程的 token、配置 API key 都不能替代。
- **隧道未连通**：按[连接指南](chatgpt-setup.md)检查 `connect` 与 `tunnel status`。面板本身不重启隧道。
- **文件哈希超预算**：可继续通过文件选择器或拖拽上传原文件，无需调大 MCP 传输限额。
- **作业或会话暂无记录**：检查配置、工作区、历史读取开关和记录范围，不把“暂无记录”当作进程已结束。

本版不提供网页配置编辑、浏览器自动附件注入或跨设备统一调度。Actions / Cloudflare 方案已保留为[后续路线](roadmap.md)，不属于面板的使用步骤。
