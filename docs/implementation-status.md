# 当前功能状态

版本：**0.14.0-preview.2**。源码仓库：[xq3427/WebCodex](https://github.com/xq3427/WebCodex)。当前为预览版，未发布 npm 包。

| 方向 | 当前状态与边界 |
| --- | --- |
| 配置与跨设备 | JSON/TOML 单文件配置、独立设备/工作区身份、可配置目录与程序路径；没有跨设备同步或调度 |
| 多工作区 | 字符串/对象简写、名称/权限、启停、离线策略和显式 worktree 登记 |
| 文本与代码 | 读取/搜索/长行续读/批量读取、创建/写入/补丁、读回哈希 |
| 修改恢复 | 记录服务文件操作、备份、预览和有条件恢复；不能恢复任意程序副作用 |
| 批量修改 | 预检/计划哈希/应用/状态与失败恢复；不承诺跨文件原子事务 |
| Git | 只读状态和差异；没有专用 stage/commit/push |
| 程序执行 | 可选 trusted-host、程序别名/profile、等待/日志/取消/pipe stdin；没有 OS 沙箱和 PTY |
| Codex 历史 | 可选只读可见记录、分页/搜索/交接；不调用模型、不恢复隐藏上下文 |
| 任务与检查点 | 独立任务及不可变修订、当前文件/作业观察、交接导出；不是自动执行器 |
| MCP 与官方隧道 | stdio/回环 HTTP、统一配置的官方客户端启动、锁/健康/协议诊断 |
| 本地面板 | 可选只读页面，查看状态/作业/索引并定位文件；无需作为启动 MCP 的前置步骤 |
| 原文件 | 原字节及显式组件诊断保留；纯 MCP 自动原生附件与正文读取没有实现，已暂停 |
| 浏览器/Actions/公网 | 不在默认依赖、命令或工具中；历史实验配置不激活功能 |
| 开源资料 | 中英文 README、配置示例、MIT、贡献/安全说明、依赖许可、CI 和仓库检查 |

当前 44 个注册工具包含 2 个组件私有工具，详见 [schema](tools.json)。ChatGPT 是否向当前对话提供某工具、是否实际调用成功，需要宿主侧确认。

本地核心完整回归为 556 通过、0 失败、2 项权限跳过；详见[测试说明](testing.md)。没有将此前失败的文件组件或本地合成浏览器页面测试宣称为真实 ChatGPT 正文读取成功。

待办集中在[路线](roadmap.md)：先完成公开仓库 CI 和实际宿主验收，再推进稳定性与使用体验。当前源码的整理不需要用户重启已有连接。
